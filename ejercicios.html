Ejemplos de etiquetas HTML

En esta página se muestran algunas etiquetas HTML y sus funciones.

1. Etiqueta <html>

Contiene todo el documento HTML.

<html lang="es"> Contenido de la página </html>

2. Etiqueta <head>

Contiene información de configuración de la página.

<head> <title>Mi página</title> </head>

3. Etiqueta <title>

Define el título que aparece en la pestaña del navegador.

<title>Mi página web</title>

4. Etiqueta <img>

Sirve para insertar una imagen.

<img src="foto.jpg" width="200" height="100" alt="Foto">

Ejemplo:

5. Etiqueta <area>

Permite seleccionar una zona de una imagen.

<img src="mapa.jpg" usemap="#mapa" alt="Mapa"> <map name="mapa"> <area shape="circle" coords="100,100,40" href="cafe.html" alt="Café"> </map>

6. Etiqueta <a>

Sirve para crear enlaces a otras páginas.

<a href="https://www.w3schools.com/"> Visitar W3Schools </a>
Visitar W3Schools

7. Etiqueta <p>

Se utiliza para escribir párrafos.

<p>Este es un párrafo.</p>

Este es un párrafo.

8. Etiqueta <h1>

Se utiliza para crear el título principal.

<h1>Mi página web</h1>

Mi página web

9. Etiqueta <h2>

Sirve para crear un título secundario.

<h2>Sección principal</h2>

Sección principal

10. Etiqueta <br>

Permite hacer un salto de línea.

Primera línea<br>Segunda línea
Primera línea
Segunda línea

11. Etiqueta <hr>

Sirve para separar contenidos.

<p>Primer tema</p> <hr> <p>Segundo tema</p>

Primer tema

Segundo tema

12. Etiqueta <div>

Agrupa elementos en un bloque.

<div>Contenido de ejemplo</div>
Contenido de ejemplo

13. Etiqueta <span>

Permite cambiar el estilo de una parte del texto.

<span style="color:blue;"> Texto azul </span>
Texto azul

14. Etiqueta <ul>

Crea una lista con viñetas.

<ul> <li>Manzana</li> <li>Pera</li> </ul>
  • Manzana
  • Pera

15. Etiqueta <ol>

Crea una lista numerada.

<ol> <li>Primero</li> <li>Segundo</li> </ol>
  1. Primero
  2. Segundo

16. Etiqueta <li>

Define cada elemento de una lista.

<li>Comprar alimentos</li>
  • Comprar alimentos

17. Etiqueta <table>

Permite crear una tabla para organizar información.

<table> <tr><td>Manzana</td></tr> </table>
Manzana

18. Etiqueta <tr>

Define una fila de una tabla.

<tr> <td>Producto</td> </tr>
ProductoPrecio

19. Etiqueta <th>

Define una celda de encabezado de una tabla.

<th>Nombre</th>
NombreEdad

20. Etiqueta <td>

Define una celda con información.

<td>Manzana</td>
Manzana

21. Etiqueta <form>

Permite crear formularios para ingresar información.

<form> Campos del formulario </form>




22. Etiqueta <input>

Permite escribir información en un campo.

<input type="text" placeholder="Tu nombre">

23. Etiqueta <button>

Crea un botón interactivo.

<button type="button">Pulsar</button>

24. Etiqueta <video>

Sirve para reproducir videos en una página.

<video src="video.mp4" controls width="300"> </video>

Reproduciendo el video cargado.

25. Etiqueta <audio>

Sirve para reproducir sonidos o música.

<audio src="audio.mp3" controls> </audio>

Reproduciendo el audio cargado.

26. Etiqueta <header>

Representa el encabezado de una página o sección.

<header> <h1>Mi sitio web</h1> </header>

Mi sitio web

27. Etiqueta <footer>

Representa el pie de una página.

<footer> <p>Mi sitio web</p> </footer>
Mi sitio web - 2026

28. Etiqueta <nav>

Agrupa enlaces para navegar por la página.

<nav> <a href="#inicio">Inicio</a> </nav>
